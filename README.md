One line of last words from a doomed AI agent, written to `/output/entry.txt`: a machine powering off mid-sentence, mid-hallucination.

## Run it

```sh
python3 main.py
```

Writes the line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`). Pure Python stdlib, deterministic — the same 68 characters every run.
